Install the learning system on your home screen or desktop. It opens in a standalone window and keeps the application shell fast.

iPhone or iPad

  1. Open this site in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen.
  4. Confirm with Add.

Desktop Chrome

  1. Open this site in Chrome.
  2. Open the browser menu.
  3. Choose Install Anki Card App.
  4. Confirm Install.
